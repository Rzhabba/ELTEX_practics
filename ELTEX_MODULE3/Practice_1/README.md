Практика 1.

Файл Task5_1.c - "черновой" вариант практики, то, что было сделано в аудитории. Во второй версии доработано согласно ТЗ.

Использование черновой версии:
После успешной сборки для запуска принимает 3 параметра:
./Task5_1 Имя_копируемого файла Имя_копии


Practice5_1.c - разделение на родительский и дочерний процесс. Ввод названия файла с клавиатуры, на его примере проверялись процессы как явление, а так же реализация тест-скрипта. 

testscript5_1.sh- скрипт-тест. Проверяет на:
1)существование файла
2) просто нажатый Enter
3) Ctrl+D вместо имени (сразу завершение)
4) Указание не файла, а каталога
5) Наличие прав на чтение (если нет то и не копирует)
